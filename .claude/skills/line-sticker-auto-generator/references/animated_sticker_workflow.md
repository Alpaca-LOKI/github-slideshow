# 動く（アニメーション）LINEスタンプ制作ワークフロー

出典：LOKIさん共有の「初心者でもできる！ChatGPTとCodexを使った動くLINEスタンプ作成手順」を、本スキルの4ジャンル（カップル／飲み屋・居酒屋／呑兵衛／ホスト・キャバ嬢）向けに一般化したもの。

静止画スタンプ（SKILL.md本体のSTEP1〜5）と違い、こちらは **Codex（デスクトップアプリ）＋画像→動画AI＋APNG変換** を組み合わせた、より工数のかかる手順。LOKIさんがパソコン上で操作する部分（動画生成の実行・ファイル保存・目視確認）と、Codexに任せる部分（画像切り出し・クロマキー透過・APNG変換・検証）に分かれる。

**ゴール**：背景透過・指定秒数だけ動くAPNG（拡張子は`.png`）をローカルに作るところまで。LINEへの申請・販売登録はLOKIさん自身が行う。

---

## 全体像

| STEP | やること | 完了の目安 |
|---|---|---|
| 1 | 作業フォルダを作る | `ai-projects/line-stamp/{ジャンル名}/` ができている |
| 2 | 元キャラクター画像とシート（8/16/24/32/40体）を準備 | `sheet.png` がある |
| 3 | Codexに画像を切り出してもらう | 透過画像N枚＋緑背景画像N枚＋動画生成用プロンプトができている |
| 4 | 画像→動画AIで動画化 | ダウンロードしたmp4がある |
| 5 | mp4を番号順に保存 | `mp4/01.mp4`〜`NN.mp4` がある |
| 6 | Codexに変換・検証を依頼 | `apng/01.png`〜`NN.png`（動くAPNG）がある |
| 7 | 完成データを目視確認 | 背景透過・動き・個数・時間を確認できた |

---

## フォルダ構成

```
デスクトップ/ai-projects/line-stamp/{ジャンル名}/
├─ sheet.png             元シート（N体を並べた画像）
├─ jobs.json             動き・指示文・時間の設定（Codexが作成・管理）
├─ refs/                 透明な切り出し画像（01.png〜NN.png）
├─ video-input/          動画生成AIへ渡す緑背景(#00FF00)画像（01.png〜NN.png）
├─ mp4/                  画像→動画AIで生成した元動画（01.mp4〜NN.mp4）
├─ apng/                 変換後の完成APNG（01.png〜NN.png）
└─ submit/               最終データをまとめる場所
```

`{ジャンル名}` は `couple` / `izakaya` / `nonbei` / `host-kyabajo` など、`persona_templates.md` のジャンルに合わせて決める。

## STEP1〜2: 元画像・シートの準備

1. カップル／飲み屋・居酒屋／呑兵衛／ホスト・キャバ嬢のいずれかのキャラ設定を確定（SKILL.md STEP1と同じ確認事項）
2. 画像生成AIでキャラクターシート（表情・ポーズ違いを複数並べたもの）を作る
3. `persona_templates.md` から選んだセリフ・動きに対応するポーズをN個（8/16/24/32/40）決める
4. 1枚の画像にN体を等間隔（例：16体なら4×4、25体なら5×5）で並べた画像を生成する。以下の条件を必ず指定する：
   - アスペクト比1:1の正方形
   - 各キャラの前後左右に余白20%
   - 背景透過
   - 全身または上半身、表情がわかる構図（顔だけのクローズアップにしない）
5. 生成された画像を `sheet.png` として保存

生成プロンプト例：

```
添付画像を参照して
-動きN パターンに合わせて元になる画像をN体生成してください。codexで切り出すので、1枚の画像にN体（縦横◯×◯体）。
-アスペクト比1:1の正方形
-それぞれの画像の隣同士、前後左右は余白を20%とること。
-背景透過で生成すること。
-全身または上半身だけにし表情がわかるような描き方をすること。
```

## STEP3: Codexへ切り出しを依頼

Codex（デスクトップアプリ、ローカルのai-projectsフォルダを開いた状態）に以下を送る。`N`・`{ジャンル名}`は実際の値に置き換える。

```
動くLINEスタンプ用の画像と動画生成プロンプトをN個分準備してください。

作業場所：現在開いているai-projectsフォルダ
シリーズ：line-stamp/{ジャンル名}
元画像：シリーズ内のsheet.png

まずAGENTS.mdがあれば読み、既存ファイルと元画像を確認してください。
シートを左上から右へ、上段から下段へ01〜Nとして扱います。
実際の画像サイズとキャラ同士のすき間を見て、切り出し位置を決めてください。

キャラと飾りを欠けずに切り出し、その幅・高さに対して各辺に約20％の透明余白を付けてください。
透明な画像はrefs/01.png〜NN.pngへ保存します。
別に、背景色#00FF00の画像をvideo-input/01.png〜NN.pngへ保存します。
緑色がキャラクターや飾りと重なる場合は、処理する前に相談してください。

画像に合うN種類の動きについて、英語の動画生成プロンプトと日本語の説明を作ってください。
顔・配色・体型・絵柄を保ち、カメラ固定、文字なし。
頭・耳・手足・飾りが常に画面内に収まるよう指定してください。
1回の動きと繰り返し回数を分け、完成時の合計を1秒・2秒・4秒のいずれかにしてください。

jobs.jsonに画像のパス・指示文・時間の設定を保存してください。
画像一覧と、指示文をコピーできる「動画生成の準備.html」も作ってください。
元画像は上書きせず、既存の完成ファイルは作り直さないでください。
まず作業案を見せ、私のOKを待ってください。
```

Codexの提案（保存先・切り出し順）を確認して「OK、作成してください」と返す。

---

## STEP4: 画像→動画AIで動画化（LOKIさんが実施）

- 使用ツールは問わない（画像添付→MP4出力ができるもの。例：Kling、Grok、fal MiniMax等）
- `video-input/01.png` から順に、`動画生成の準備.html` にある英語プロンプトをコピペして生成
- 完成スタンプの合計再生時間は **1秒・2秒・4秒のいずれか**（繰り返し込み）を目安にする
- 生成結果チェック項目：指示した動きが分かるか／顔や体型が崩れていないか／耳・手足が画面から切れていないか／背景が緑の無地か
- 完了したらMP4をダウンロード

---

## STEP5: mp4を保存

`01.png` から作った動画は `mp4/01.mp4`、`02.png` は `mp4/02.mp4`……という具合に番号を合わせて保存する。拡張子の二重付け（`01.mp4.mp4`）に注意。

---

## STEP6: Codexへ変換・検証を依頼

### 6-1. 現状確認プロンプト

```
動画生成が終わりました。まず現状確認だけをしてください。
作業場所：現在開いているai-projectsフォルダ
シリーズ：line-stamp/{ジャンル名}
元動画：シリーズ内のmp4/01.mp4〜NN.mp4
設定：シリーズ内のjobs.json

フォルダ構成、元画像、参照画像、動画、設定、既存の処理プログラムを確認してください。
必要な動画が全部あるか、ファイル名に重複や抜けがないかを調べてください。
まだ変換・削除・上書き・インストールはしないでください。
最後に「この内容で作業を開始してよいですか？」と確認してください。
```

### 6-2. 01番だけ試作するプロンプト

```
確認した内容で、まず01番だけ試作してください。

元画像・元動画は上書きしないでください。
背景を透明にし、動くLINEスタンプ用のAPNGを作成してください。拡張子は.pngです。
既存のプログラムが使えれば再利用し、なければ再実行できる変換・検証プログラムを_shared内に作成してください。

動画の全体を確認し、必要な動きが入る開始・終了時刻を選んでください。
制作時点のLINE公式仕様を確認し、最大320×270、片辺270以上、5〜20コマ、
繰り返し1〜4回、1MB以下、背景透過を検証してください。
変換後の実データから、寸法・コマ数・合計時間・容量・透明度を確認してください。
動きがない画像、全透明、全不透明、体や飾りが欠けた画像を合格にしないでください。

新規出力先はシリーズ内のapngです。既存ファイルがあれば勝手に上書きせず相談してください。
ブラウザで白・暗い色・市松模様の背景を切り替えて確認できるページを用意してください。

01番の保存先と確認方法を教え、私が見た目を確認するまで残りは処理しないでください。
申請・販売登録は不要です。
```

### 6-3. 残りを進めるプロンプト

01番の見た目を確認後：

```
01番の動きと背景を確認しました。
同じ方針で02〜05を作成し、それぞれの動画に合う区間と設定を選んでください。
確認結果と保存先を教えてください。06〜NNは、私が次にOKと言ってから進めてください。
すでに合格した01番や元画像・元動画は変更しないでください。
```

### 6-4. 完成確認プロンプト（全数そろった後）

```
N個の完成データを確認してください。
設定上の値ではなく、保存済みAPNGを読み取って結果を出してください。
01.png〜NN.pngの個数・名前・再生時間・繰り返し・寸法・コマ数・容量・透明度を確認し、
1個ずつ合格／要確認の一覧にしてください。
失敗したものを完成フォルダへ混ぜず、未確認があれば明記してください。
申請・販売登録は行わないでください。
```

## STEP7: 完成データの確認チェックリスト

- [ ] `apng/` にN枚あり、番号の抜け・重複がない
- [ ] ブラウザで再生すると指示した動きが見える
- [ ] 背景を白／暗い色／市松模様に変えても四角い背景が残らない（透過できている）
- [ ] 緑の縁・不要な影・文字が目立たない
- [ ] 動いている間もキャラの体・飾りが欠けない
- [ ] LINE公式仕様（下表）を満たす

| 項目 | 基準 |
|---|---|
| 画像サイズ | 横320×縦270以内、片辺は270以上 |
| コマ数 | 1個あたり5〜20 |
| 繰り返し回数 | 1〜4回 |
| 合計再生時間 | 1秒・2秒・4秒のいずれか（目安） |
| 容量 | 1個1MB以下 |
| 背景 | 透明（全消去になっていないことも確認） |

## Codexが裏で行っている処理（参考）

| 処理 | 内容 |
|---|---|
| 動画区間選択 | 使いたい動きが入っている部分を切り出す |
| コマ取り出し | 動画から連続静止画を抽出 |
| クロマキー | 緑背景(#00FF00)を透過に変換 |
| 輪郭整え | 毛や輪郭に残る緑の縁・薄い縁を除去 |
| サイズ統一 | 動く範囲全体が入るよう完成画像の枠に収める |
| APNG化 | 複数コマに表示時間・繰り返し回数を付与 |
| 容量調整 | 色数・コマ数を減らして1MB以下に |
| 検証 | 保存済みファイルの寸法・時間・容量・透過を実測確認 |

## よくあるつまずき

- **`refs`と`video-input`のどちらを動画生成AIに渡すか迷う** → 渡すのは`video-input`（緑背景）。`refs`は透明な元素材として保持するだけ。
- **前回の設定ファイル形式（`stamps`配列）と今回（`jobs`配列）が違う** → Codexに互換性を確認させ、単純な差し替えはしない。
- **静止画スタンプの`persona_templates.md`のセリフをそのまま動きの元ネタに使ってよい** → 「ありがとう」なら会釈+キラキラ、「乾杯！」ならグラスを掲げる動作、のように各セリフを具体的な動きに翻訳してからCodexへの依頼文に含める。
