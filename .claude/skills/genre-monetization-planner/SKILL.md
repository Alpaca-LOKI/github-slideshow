# ジャンル別マネタイズ・プランナー（5STEPフレームワーク）

成人向け（エロ）ジャンルのSNSアカウント運営を、感覚ではなく「市場→ターゲット→欲求→発信→商品」の逆算と、数値によるボトルネック診断で設計するためのスキル。

## このスキルの立ち位置（重要）

このスキルが自動化するのは**戦略・数値・型化**の部分だけ。以下は明確に対象外とする。

- 実在しないキャラクターの容姿・人格・性的な描写そのものの生成
- 性的に露骨な投稿文言・キャッチコピーの代筆
- キャラクター画像の生成

STEP2（キャラ設計）では、`references/step2_character_sheet.md` の**質問付き空欄シート**を提示するだけに留め、中身はユーザー自身に埋めてもらう。Claudeが自発的に容姿や口調のサンプル文を書き足さないこと。

## ワークフロー

ユーザーの発言から、5STEPのどこを聞かれているか判断し、該当するreferenceを読み込んで、ユーザー自身のジャンル・実測データを当てはめた「埋まったシート」を返す。複数STEPにまたがる相談（例：「ジャンル決まったから次どうする」）なら、順番に案内する。

| STEP | 何をするか | 参照ファイル |
|---|---|---|
| 1. ジャンル選定 | 4条件スコアリング＋市場逆算計算 | `references/step1_genre_scoring.md` |
| 2. キャラ設計 | 空欄シート（内容は生成しない） | `references/step2_character_sheet.md` |
| 3. SNS集客 | 投稿分類＋伸びた投稿の要因分解 | `references/step3_sns_growth.md` |
| 4. 導線設計 | 無料→低単価→購入のマッピング | `references/step4_funnel.md` |
| 5. 売上逆算 | 計算機＋ボトルネック診断 | `scripts/revenue_calculator.py` |

### STEP1: ジャンル選定

`references/step1_genre_scoring.md` を読み、需要・SNS集客可能性・商品化可能性・差別化の4軸でユーザーの候補ジャンルを一緒にスコアリングする。「フォロワーが増えそうか」ではなく「客単価いくら×月何件で目標に届くか」まで数字に落とすのがゴール。候補が複数あれば比較表にする。

### STEP2: キャラ設計

`references/step2_character_sheet.md` の空欄シートをそのまま提示し、STEP1のターゲット・欲求から逆算して「どんな軸で埋めるべきか」のヒント（一般論のみ、具体的な人物像は書かない）を添える。ユーザーが埋めた内容を見せてくれたら、STEP1のターゲット設定と一貫しているかのレビューはしてよい。

### STEP3: SNS集客

`references/step3_sns_growth.md` の投稿分類（集客／日常／ファン化）を使って、ユーザーの直近投稿を分類する。伸びた投稿については「画像・構図」「最初の一文」「投稿時間」「フォロワー数の推移」を聞き出し、post-mortemテンプレートに記録する。数字は表示回数→プロフィールアクセス→フォロー→反応数→商品ページアクセス→購入の順で追い、どこで離脱しているかを特定する。

### STEP4: 導線設計

`references/step4_funnel.md` を使って、無料コンテンツ→低単価商品（3,000〜10,000円目安）→本命商品の流れに、実際の投稿・商品をマッピングする。商品は「反応が多かった投稿・質問が多いテーマ」から逆算して発想させる（Claudeが商品内容を発明しない）。

### STEP5: 売上逆算・ボトルネック診断

`scripts/revenue_calculator.py` を使う。3つのモードがある。

```bash
# モードA: 現状の数値から売上を予測
python3 scripts/revenue_calculator.py forecast --list-size 500 --reply-rate 0.2 --purchase-rate 0.2 --unit-price 10000

# モードB: 目標売上から必要な数値を逆算（他3つの数値を固定して1つを求める）
python3 scripts/revenue_calculator.py solve --target-revenue 1000000 --reply-rate 0.2 --purchase-rate 0.2 --unit-price 10000

# モードC: 実測値と目標売上から、どこがボトルネックかを診断
python3 scripts/revenue_calculator.py diagnose --list-size 500 --reply-rate 0.2 --purchase-rate 0.2 --unit-price 10000 --target-revenue 1000000
```

計算結果が出たら、必ず「売上＝リスト数×リプ率×購入率×客単価」のどこを改善するのが一番効率がいいか（現状値から一番遠い/一番上げやすい変数はどれか）をコメントする。「とにかく投稿を増やす」ではなく、ボトルネックを特定してから打ち手を提案すること。
