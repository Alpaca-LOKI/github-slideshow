# STEP2: キャラクター設計シート（空欄テンプレート）

**重要**: このシートはユーザー本人が埋めるための質問リストです。Claudeは項目ごとのヒント（一般的な観点）だけを添え、具体的な容姿・人格・口調のサンプル文や性的な描写は生成しません。ユーザーが自分で埋めた内容を貼ってくれた場合は、STEP1で決めたターゲット・欲求と矛盾がないかのレビューのみ行います。
