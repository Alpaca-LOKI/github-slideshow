# STEP4: 無料→低単価→購入の導線設計

フォロワーが増える＝売上が増える、ではない。「もっと見たい」から「買いたい」への導線を意図的に作る。

## 基本構造

```
SNS投稿 → 興味を持つ → 無料コンテンツを見る → もっと見たいと思う → 有料商品（低単価）を購入 → 本命商品へ
```

ポイントは「無料コンテンツだけでも満足できるが、有料ならさらに価値がある」という関係を作ること。無料が有料の劣化版になっていると導線が機能しない。

## 導線マップ・テンプレート

| ファネル段階 | 役割 | 該当する投稿・コンテンツ | 価格帯の目安 |
|---|---|---|---|
| 集客（SNS投稿） | 新規接触 | | 無料 |
| 無料コンテンツ | 価値を体感させる | | 無料 |
| 入口商品 | 「試してみよう」の心理的ハードルを下げる | | 3,000〜10,000円目安 |
| 本命商品 | メインの収益源 | | 客単価はSTEP1の逆算値に合わせる |

## 商品発想は欲求から逆算する

Claudeは商品の具体的な中身を発明しない。以下のデータをユーザーから聞き出し、そこから商品の方向性を一緒に整理する。

- 異常に反応が良かった投稿はどれか
- 同じテーマについて質問・DMが繰り返し来ていないか
- 「もっと見たい」と言われた内容は何だったか

このデータが3つとも同じ方向を指しているなら、それが商品化の最有力候補。需要を確認してから商品を作る、の順番を崩さない。
