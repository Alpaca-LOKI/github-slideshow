# STEP3: SNS集客の型化

「バズったかどうか」ではなく「再現できる型」を見つけることが目的。

## 投稿の3分類

投稿ごとにどの役割を担っているか分類する。1投稿が複数の役割を兼ねてもよい。

| 分類 | 目的 | 例に見るポイント |
|---|---|---|
| 集客投稿 | 新規に見つけてもらう | 構図・服装・表情、文章なら意外性・共感・続きが気になる一言 |
| 日常投稿 | 生活を感じさせ親近感を作る | 仕事・休日・食事・趣味など |
| ファン化投稿 | このキャラ自身に興味を持たせる | 価値観・悩み・フォロワーとのやり取り |

直近の投稿ログをこの3分類で振り返り、比率が偏りすぎていないか確認する（集客投稿ばかりだとファン化しない、ファン化投稿ばかりだと新規が増えない）。

## 数字を追う順番

フォロワー数だけを追わない。以下の順で数字を記録し、どこで離脱しているかを特定する。

1. 表示回数
2. プロフィールアクセス
3. フォロー
4. 反応数（いいね・コメント・保存など）
5. 商品ページへのアクセス
6. 購入

例：表示は多いのにプロフィールアクセスが少ない → 投稿単体は伸びてもプロフィールに興味を持たれていない（プロフィール文・固定投稿の問題）。プロフィールアクセスはあるのにフォローが少ない → プロフィール自体の魅力・導線の問題。

## 伸びた投稿のポストモーテム・テンプレート

伸びた投稿・伸びなかった投稿の両方を記録し、パターンを言語化する。

```
投稿日時：__________
分類（集客/日常/ファン化）：__________
画像・構図の特徴：__________
最初の一文／フック：__________
投稿時間帯：__________
表示回数：______ → プロフィールアクセス：______ → フォロー：______ → 反応数：______
なぜ伸びた／伸びなかったと考えられるか：__________
次回に活かす具体的な変更点：__________
```

このログを一定数貯めたら、「共通して伸びている要素」を横断で比較し、型として抽出する。単発の成功を「運が良かった」で終わらせない。
