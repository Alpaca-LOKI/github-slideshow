# STEP1: ジャンル選定シート

目的：「なんとなく発信」ではなく、市場 → ターゲット → 欲求 → 発信 → 商品を一本につなぐ。

## 4条件スコアリング（各5点満点、候補ジャンルごとに記入）

| 評価軸 | 見るポイント | 候補A | 候補B | 候補C |
|---|---|---|---|---|
| ①需要 | すでにお金を払っている人がいるか。検索・SNSでの言及量は | | | |
| ②SNS集客力 | このジャンルの投稿は伸びやすいか。表示→フォローに繋がりやすいプラットフォームがあるか | | | |
| ③商品化可能性 | 有料コンテンツ・サービスとして形にできるか。原価・制作時間は現実的か | | | |
| ④差別化余地 | 既存の強豪と違う切り口を作れそうか（見た目×性格×設定×ストーリーの掛け算） | | | |
| **合計** | | | | |

合計点が最も高い候補を選ぶ。ただし①需要が2点以下の候補は他が高くても避ける（売る場所がない）。

## 市場逆算計算（選んだジャンルで実施）

以下をユーザーの実測・想定値で埋める。

```
月間目標売上 = ¥___________
想定客単価   = ¥___________
必要購入件数 = 月間目標売上 ÷ 想定客単価 = ___________ 件/月
```

例：目標100万円、客単価5,000円 → 必要購入件数 = 200件/月。

この件数が「今のフォロワー規模・投稿ペースで現実的か」を次にSTEP5の売上逆算計算機で検証する。

## 市場→ターゲット→欲求→発信→商品の一本化

1. 市場：選んだジャンルの中で、どの層が実際にお金を使っているか
2. ターゲット：その中でも具体的にどんな属性・状況の人か
3. 欲求：その人が満たしたい欲求は何か（見た目消費／共感／優越感／非日常など）
4. 発信：その欲求を刺激する投稿はどんな切り口か（STEP3で型化）
5. 商品：その欲求に対して何を売るか（STEP4で導線化）

この5項目が矛盾なく一直線につながっているか確認する。どこかで飛躍がある場合、そこがボトルネックになりやすい。
